# 🏘️ 나의 두번째 인생

공부하고, 일하고, 취미를 즐기고, 투자도 하는 **작은 도시**에서 또 하나의 인생을 사는 웹 게임을 만들고 있습니다.
지금은 **메인 홈페이지, 로그인, 기본 게임 화면**이 있습니다. 게임 그림(맵·캐릭터·건물)은 하나씩 직접 디자인해서 넣을 예정이라, 지금은 자리만 잡은 임시 모양입니다.

- 예전 게임(주식 시뮬레이션 → 마을 게임)은 52단계에서 모두 지웠습니다. 코드는 Git 기록에 남아 있습니다(예: 태그 `pixel-v1`, 52단계 바로 앞 커밋).
- 외부 라이브러리 없이 Node.js 내장 기능과 HTML·CSS·JavaScript만 씁니다.
- 만든 과정은 [제작과정.md](제작과정.md)에 정리했습니다.

## 실행

```bash
node server.js
```

브라우저에서 http://localhost:5000 을 엽니다.

### 다른 사람에게 보여 주기 (임시 인터넷 주소)

1. 한 번만 설치: `winget install Cloudflare.cloudflared`
2. 프로젝트 폴더의 **`share.bat`** 을 더블클릭하면 서버가 켜지고 `https://….trycloudflare.com` 주소가 나옵니다.

- 창을 닫거나 PC를 끄면 주소가 사라지고, 다시 켜면 새 주소가 나옵니다.
- 구글 로그인은 Google Cloud에 등록한 주소에서만 됩니다(아래 참고). 임시 주소에서는 닉네임·비밀번호 로그인을 쓰세요.

## 메인 홈페이지 (`/`)

흑백 일러스트 느낌(밝은 회색 바탕, 검은 덩어리와 흰 별, 선 그림)이고, **한 화면 단위**로 나뉩니다.

1. **메뉴바 + 히어로**: 가운데 입체 글자 로고, 오른쪽 로그인/로그아웃(픽셀 아이콘). 입체 제목 "나의 두번째 / 인생", 도시 소개("공부하고, 일하고, 취미를 즐기고, 투자도 하는 작은 도시"), 공부·일·취미·투자를 나타내는 책·가방·팔레트·동전 선 그림. **돌아다니는 캐릭터 두 마리**: 게임 속 동글동글 흰 캐릭터(`sprites.js` 그림 그대로)가 **웹페이지 전체(영역 1·2 어디든)** 에 목적지를 골라 8방향 모습·걸음걸이로 걸어가고, 도착하면 잠깐 쉬었다가 또 다른 곳으로 갑니다. 페이지 위에 있어서 스크롤하면 페이지와 같이 움직이고, 클릭을 막지 않습니다(PC 88px, 휴대폰 64px). **가끔(9~16초마다) 둘이 모여 마주 보고 대화**합니다: 픽셀 말풍선(흰 바탕 + 굵은 검은 테두리 + 계단 모서리 + 오른쪽·아래 안쪽 회색 그늘) + 검은 픽셀 글씨(무료 한글 픽셀 폰트 갈무리14, 14px, OFL), 테두리 픽셀 1칸 = 4px. 말풍선은 상대 쪽으로 펼쳐지고 꼬리 끝은 말하는 캐릭터 머리 위(왼쪽 캐릭터면 왼쪽 아래로, 오른쪽이면 오른쪽 아래로 꺾임). 한 줄씩 번갈아 말하고(긴 말은 더 오래), 끝나면 흩어집니다. 대화는 `TALKS` 목록(공부·일·취미·투자·날씨 이야기 6가지)에서 고릅니다. 움직임 줄이기 설정이면 아래쪽 양 끝에 가만히 서 있고 대화도 하지 않습니다.
2. **PC에서도 모바일에서도 + 로그인**: 왼쪽은 기기별 조작 안내(PC: 방향키나 WASD로 움직이고 E 버튼으로 상호작용 / 모바일: 조이스틱 + E 버튼 + 가로 전체화면), 오른쪽은 **로그인 카드**. 로그인하면 카드가 "○○님, 환영해요"로 바뀝니다.

첫 화면 맨 아래 **↓ 화살표**나 메뉴바의 "로그인"을 누르거나, 마우스 휠을 한 번 굴리면 다음 영역으로 0.9초 동안 부드럽게 넘어갑니다(움직임 줄이기 설정이면 바로 이동).

## 게임 화면 (`/play`)

- 로그인한 사람만 들어옵니다. 로그인 카드의 **게임 시작**을 누르면 열리고, 로그인 안 했거나 로그아웃하면 메인으로 돌아갑니다.
- 메뉴바 없이 화면 전체가 게임 화면입니다.
- **실수 막기**: 게임 화면에서는 Ctrl + 마우스 휠(터치패드 두 손가락 확대·축소 포함)과 Ctrl + +/−/0으로 화면이 커지거나 작아지지 않습니다.
- **Ctrl+W 막기 (전체화면)**: 창 모드에서는 브라우저가 Ctrl+W를 먼저 처리해서 웹페이지가 막을 수 없습니다. 그래서 PC에서 게임에 들어오면 **"게임 시작" 창**이 뜨고, 누르면 전체화면 + 키보드 잠금(크롬·엣지)이 켜집니다. 이때 Ctrl+W(Mac은 ⌘+W)를 누르면 창이 닫히지 않고 게임 안 **확인 창 "조심하세요! Ctrl + W를 누르면 창이 닫힐 수 있습니다! 정말 창을 닫을까요?"**이 뜹니다.
  - **아니오**(기본 선택, ESC로도): 게임으로 돌아감. **예**: 웹페이지는 창을 직접 닫을 수 없어서 전체화면·키 잠금을 풀고 위쪽에 "이제 Ctrl + W를 누르면 창이 닫혀요 [게임 계속하기]"를 띄움 → 한 번 더 누르면 닫힘. ←→(A/D)로 고르고 Enter·Space·E로 누름.
  - 짧은 ESC는 지금처럼 게임 메뉴, ESC를 **길게** 누르면 전체화면이 풀립니다(브라우저 규칙). 전체화면이 아니게 되면 위쪽에 "창 모드에서는 Ctrl + W를 막을 수 없어요 [전체화면으로]" 띠가 뜹니다.
  - 휴대폰·태블릿은 Ctrl+W가 없어서 시작 창 없이 처음 화면을 누르면 전체화면이 됩니다. 키보드 잠금이 없는 브라우저(파이어폭스·사파리)에서는 Ctrl+W를 막을 수 없습니다.
- **메뉴 창(ESC)**: ESC(휴대폰·태블릿은 오른쪽 위 ☰ 버튼, PC에는 이 버튼이 없음)를 누르면 "나의 두번째 인생"(굵은 픽셀 글꼴 갈무리11 Bold, 22px) 픽셀 메뉴 창이 뜹니다 — **게임으로 돌아가기**(파랑), **이용방법**(조작 안내 창, 확인을 누르면 뒤로 가기처럼 메뉴로 돌아옴), **전체 화면 / 기본 화면**(지금 상태에 따라 글자가 바뀌는 전환 버튼, 메뉴로 일부러 기본 화면으로 바꾸면 창 모드 안내 띠는 안 뜸), **설정**(소리·화면 설정은 준비 중), **홈페이지로 이동**, **로그아웃**(빨강, 로그아웃 후 메인으로). 열려 있는 동안 캐릭터는 움직이지 않고 ↑↓(W/S)로 고르고 Enter·Space·E로 누릅니다. 설정에서 ESC는 메뉴로, 메뉴에서 ESC는 게임으로.
- **첫 맵 — 잔디밭에 주택 한 채** (`town.js`): 가로 40칸 × 세로 24칸(1280×768픽셀) 잔디밭. 맵 밖으로는 못 나가고, 카메라는 맵 끝에서 멈춥니다. 처음 서는 곳은 집 앞마당.
  - **화면 배율**: 기본 2배, 화면이 맵보다 크면(큰 모니터·브라우저 축소) 맵이 화면을 꽉 채울 때까지 정수 배(3·4…)로 키워 빈 공간이 없습니다.
  - **꾸밈**: 집 양옆 길가에 벤치 두 개, 맵 가장자리·빈 풀밭에 원뿔 나무 21그루, 길 왼쪽 끝에 주황 화살표 판 두 개(← 도시, 안내소 →) 달린 길 안내 표지판.
  - **튜토리얼 공간**: 처음 서는 곳(바깥 `field`·집 안 `home`)은 튜토리얼 공간입니다. 현관에서 처음 서는 곳을 지나 **왼쪽 끝까지 흙길**이 있고, 끝의 "도시" 표지판 앞에서 **E 도시로 떠나기**(안내소에서 기본 UI를 받은 뒤에만, 서버도 확인) → 확인 창(떠나면 다시 못 돌아온다는 안내) → **도시 입구**(`city`). 떠나면 서버 계정에 `tutorialDone`이 적혀 다음부터는 도시 입구에서 시작합니다.
  - **장면**: `SCENES`에 바깥(`field`)·집 안(`home`)·도시 입구(`city`)가 있고 `useScene`으로 바꿉니다. 문 앞에서 **E 들어가기**(화면이 잠깐 어두워졌다 밝아짐), 집 안 현관 매트에서 **E 나가기**.
  - **집 안**(20×12칸): 벽지 벽·나무 마루·러그, 침대·협탁·책장·TV·소파·탁자·조리대·냉장고·식탁·화분, 커튼 창문·액자·벽시계.
  - **NPC "안내원 봄"**: 가까이서 **E 대화** → 화면 아래 픽셀 대화창. E·Enter·Space·누르기로 다음 말, ESC로 닫기. 대화 중에는 못 걷습니다. 처음 대화를 끝까지 들으면 **기본 UI를 줍니다**("기본 UI를 받았어요!" 알림, 서버 계정에 `basicUI` 기록). 받은 뒤에는 다른 대사. 받으면 화면 테두리에 **기본 UI**가 생깁니다.
  - **NPC 근처**: NPC 몸·이름표와 겹쳐 서지 않게 둘레는 못 지나가고, 조금 떨어진 곳에서도 E로 말을 걸 수 있습니다.
  - **기본 UI**: 왼쪽 위 계절·날짜·날씨·시각(현실 1초 = 게임 1분, 계절마다 28일, 날씨는 날마다 계절별 확률로, 겨울엔 눈), 오른쪽 위 현금(처음 50,000원, 새 계정은 1일 오전 8시부터), 왼쪽 아래 가방 버튼(스티커 붙은 파란 배낭 픽셀 그림, B로도 열기). 가방 창은 배낭과 같은 파란색(남색 테두리, 위에 걸친 제목 판, 노란 X 닫기, 움푹한 칸). 처음 받은 가방은 3칸. 게임 시간은 서버에 저장되어 이어집니다.
  - **하늘**: 밤(오후 8시~새벽 4시 가장 어둡고 그 앞뒤로 서서히)과 해 질 녘 주황빛, 흐린 날·비 오는 날의 흐림, 비(빗줄기)·눈(눈송이)이 맵 위에 보입니다. 집 안은 비·눈이 없고 밤에도 조금만 어둡습니다. 밤에는 집 창문·처마 등에 불빛이 켜집니다(`LIGHTS`). 집 안 창문 너머도 바깥과 같은 하늘(밤·노을·흐림·비·눈, `SKY_GLASS`)이고, 벽시계 바늘은 게임 시각대로 움직입니다. 맑은 밤엔 기본 UI 날씨 아이콘이 달.
  - **잔디**: 칸마다 풀결·풀 무더기·작은 꽃이 조금씩 달라 넓어도 단조롭지 않습니다.
  - **주택**(가운데, 가로 6칸 × 세로 3줄, 지붕은 위로 솟음): 굴뚝, 붉은 기와 박공지붕(기와 줄·이음새·용마루)과 흰 처마 띠, 크림색 나무 판자 벽과 모서리 기둥, 가운데 현관문(차양·처마 밑 등·작은 창·판넬·손잡이) 양쪽에 초록 덧창 창문과 창가 화분, 돌 기단과 두 단 계단. 오른쪽으로 그림자가 지고, 지나갈 수 없으며 뒤로 가면 가려집니다.
  - **바닥**은 `GROUND` 지도(글자 한 칸 = 바닥 한 칸: `g` 잔디, `.` 보도, `k` 점자블록, `q` 광장, `p` 주차장, `R` 차도, `Z` 횡단보도), **물건**은 `place(...)` 목록(칸 번호)으로 정합니다. 도로·건물(카페·가게·빌라)·나무·가로등·신호등·벤치·분수·자판기·차 같은 그림과 차선 무늬 코드는 남아 있어 `place('종류', 색번호, x, y, 가로칸, 세로줄)` 한 줄로 다시 놓을 수 있고, 놓으면 그림자·부딪힘·앞뒤 가림도 자동입니다.
- 화면이 늘 내 캐릭터를 가운데에 두고 따라갑니다. 땅 끝이 없어서 어느 쪽으로든 계속 걸어갈 수 있습니다.
- **PC**: 방향키나 WASD로 걷습니다(화면에서 1초에 240px). 방향키 방향 그대로(위 = 화면 위쪽), **두 키를 같이 누르면(↑→ 등) 45도 대각선**으로 걷고 빠르기는 같습니다. E로 상호작용(문 들어가기·나가기, NPC 대화). 할 수 있는 곳 가까이 가면 위에 "E" 표시가 뜹니다.
- **휴대폰**: 왼쪽 아래 조이스틱(많이 밀수록 빨리), 오른쪽 아래 E 버튼. 게임 화면을 처음 누르면 전체화면 + 가로 고정(되는 브라우저만).
- **조작 안내 창**: **계정을 만들고 처음 게임에 들어왔을 때 한 번만** 화면 가운데에 픽셀 안내 창(말풍선과 같은 흰 바탕·검은 계단 테두리·회색 그늘, 갈무리14 글씨, 자판 모양 키)이 뜹니다. PC는 키보드(↑←↓→·WASD 움직이기, E 말 걸기·사용하기, 0~9·Q 스킨 미리 보기), 휴대폰은 조이스틱·E 버튼·전체화면 설명. "확인" 또는 Enter·E·Esc·Space로 닫고(닫을 때 누른 E는 게임으로 넘어가지 않음), 메뉴 → **이용방법**으로 언제든 다시 엽니다. 처음 닫을 때 서버가 계정에 "봤음"(`guideSeen`)을 적어서, 다른 기기·브라우저에서도 다시 저절로 뜨지 않습니다(`/api/me`가 알려 주고 `/api/guideSeen`으로 기록).

### 캐릭터 (`sprites.js`)
- **하얗고 동글동글한 작은 캐릭터**(16×18픽셀): 둥근 머리와 몸이 하나로 이어지고, 점 눈 두 개와 짧은 다리. 바닥 픽셀보다 2배 크게 그립니다(`SPRITE.scale`).
- **스킨 두 가지** (몸은 모두 같아서 스킨 그림 한 장이면 누구에게나 맞음, 그리는 순서: 몸 → 전신 스킨 → 얼굴 → 모자)
  - **모자 스킨**(`PARTS.hat`): 머리 위(0~5줄)와 머리 테두리에 겹쳐 그림. 새싹, 고양이 귀, 야구 모자(파랑·빨강), 요리사 모자, 왕관, 털모자, 마법사 모자, 헤드폰.
  - **전신 스킨**(`PARTS.suit`): 몸 전체를 옷 색으로 덮고 얼굴 자리만 뚫린 옷. 개구리 옷(머리 위 두 눈), 곰 옷(둥근 귀), 공룡 옷(등 가시). `makeSuit`가 몸 모양에서 옷을 자동으로 만들고 방향마다 얼굴 구멍을 뚫어 주므로, **머리 위 장식만 그리면** 새 전신 스킨이 됩니다.
- 스킨은 **모양 + 색**: `a`/`A`(스킨 색과 그늘)로 그린 모양은 색만 바꿔 여러 스킨이 됩니다(야구 모자 파랑·빨강처럼). `y` 금색·`r` 빨강·`g` 초록·`p` 분홍·`k` 검정은 색이 고정된 장식. 몸 색(`color`)도 바꿀 수 있습니다.
- **임시 미리 보기**: 게임 화면에서 숫자 키 `0`~`9`로 모자, `Q`로 전신 스킨을 차례로 바꿔 볼 수 있습니다(`0` = 모자 없음). 상점이 생기면 지울 기능입니다.
- 그림은 **글자 한 칸 = 픽셀 하나**: `o` 테두리, `w` 몸, `W` 몸 그늘, `e` 눈, `.` 비움. 한 줄은 꼭 16글자.
- **8방향**: 오른쪽 기준 5가지 그림 — `s` 정면, `se` 오른쪽 아래, `e` 오른쪽, `ne` 오른쪽 위, `n` 뒤 — 을 그리고, 왼쪽 세 방향은 좌우를 뒤집습니다. 몸은 한 장, 눈은 방향마다 위치만 다르고(뒤쪽은 안 보임), 챙이 있는 야구 모자만 방향별 그림이 있습니다. 없는 방향은 비슷한 방향 그림을 대신 씁니다(`FALLBACK`).
- 걸을 때는 짧은 다리가 1칸씩 번갈아 올라갑니다(자동).
- 새 모자는 `PARTS.hat`에 정면 그림(`s`)을 넣고 `HATS`에, 새 전신 스킨은 `PARTS.suit.이름 = makeSuit([머리 위 장식])`을 넣고 `SUITS`에 추가하면 됩니다.
- 아직 스킨을 계정에 저장하거나 상점에서 사는 기능은 없습니다.

## 로그인 — 구글 계정 또는 닉네임 + 비밀번호

### 구글 계정
- 로그인 카드의 **"Google 계정으로 로그인"** 을 누르고 계정을 고릅니다. 처음 온 구글 계정은 **닉네임만 정하면** 계정이 만들어지고, 다음부터는 버튼 한 번으로 들어옵니다.
- 서버는 구글이 준 확인증(ID 토큰)이 진짜인지 구글에 물어봅니다(`tokeninfo`, 확인증은 주소가 아니라 본문으로 보냄). **우리 앱용(aud)·구글 발급(iss)·기간 안 지남(exp)·이메일 인증됨**을 모두 확인한 뒤에만 들어갑니다.
- 계정에는 **비밀번호 없이 구글 계정 고유 번호(sub)만** 저장합니다. 이메일·이름·사진은 저장하지 않습니다. 구글로 만든 닉네임은 비밀번호로 로그인할 수 없습니다.
- 설정: Google Cloud의 OAuth **클라이언트 ID**(공개 값)만 씁니다. 서버의 `GOOGLE_CLIENT_ID`(환경 변수로 바꿀 수 있음)에 들어 있고, 화면은 `/api/config`로 받아 갑니다. **클라이언트 보안 비밀(secret)은 쓰지 않습니다.**
- 등록된 주소: `http://localhost`, `http://localhost:5000`. 고정 도메인을 연결하면 그 주소를 "승인된 자바스크립트 원본"에 추가하면 됩니다. 앱이 "테스트" 상태인 동안은 **테스트 사용자로 등록한 계정만** 로그인됩니다.

### 닉네임 규칙 (새로 만들 때)
| 규칙 | 막히는 예 |
|---|---|
| 한글(완성된 글자)·영어만 | `ant123`, `마을!`, `ㅋㅋㅋ` |
| 띄어쓰기 불가 | `나의 마을` |
| 2~10글자 | `가`, `abcdefghijk` |
| 중복 불가(대소문자 무시) | `Gyeol`이 있으면 `GYEOL`, `gyeol` |
| 욕설·비하·성적 단어 불가(한국어·영어 목록, 들어 있기만 해도) | `씨발친구`, `FuckYou` |
| 운영진 사칭 불가 | `운영자`, `관리자님`, `Admin`, `GM`(그 자체) |

닉네임 칸에 입력하면 0.3초 뒤 서버(`/api/nameCheck`)가 규칙·중복을 확인해 바로 알려 줍니다. 최종 판단은 계정을 만들 때 서버가 한 번 더 합니다.

### 닉네임 + 비밀번호
- 로그인 카드의 "닉네임·비밀번호로 로그인"을 펼칩니다. 처음 쓰는 닉네임이면 계정이 자동으로 만들어집니다.
- 이미 있는 닉네임이면 **비밀번호가 같을 때만** 로그인됩니다. 5번 연속으로 틀리면 30초 동안 잠깁니다.
- 비밀번호는 원문으로 저장하지 않습니다. 소금(salt)을 친 scrypt 해시만 저장합니다.
- 로그인은 HttpOnly 쿠키로 30일 유지됩니다. 서버에는 쿠키 값의 해시만 저장되므로 서버를 다시 켜도 로그인이 이어집니다.
