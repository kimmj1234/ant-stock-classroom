# 🐜 개미 투자 교실 — 다 같이 하는 픽셀 주식 시뮬레이션 학습 게임

링크에 접속한 사람이 모두 **같은 주식시장**에서 함께 투자하는 게임입니다.
위에서 내려다본 픽셀 사무실을 방향키로 돌아다니며, 컴퓨터(증권 HTS)로 30개 종목을 사고팝니다.
매일 날씨가 바뀌고 신제품·신약·실적·금리·유가 같은 사건이 **AI 없이 자동으로** 일어나 주가를 움직입니다.
TV에서 사건의 📘 배우기를 읽으며 주가가 왜 움직이는지 익힙니다.

- 외부 라이브러리 없이 Node.js 내장 기능과 HTML·CSS·JavaScript만 씁니다. 그래픽은 모두 코드로 픽셀을 찍어 그립니다.
- 만든 과정은 [제작과정.md](제작과정.md)에 정리했습니다.

## 실행

```bash
node server.js
```

브라우저에서 http://localhost:5000 을 엽니다. 같은 컴퓨터의 다른 창(또는 다른 브라우저)으로 접속하면 여러 명이 함께 할 수 있습니다.

## 입장 (닉네임 + 비밀번호)

- 처음 쓰는 닉네임이면 계정이 **자동으로 만들어집니다**.
- 이미 있는 닉네임이면 **비밀번호가 같을 때만 로그인**됩니다. 5번 연속으로 틀리면 30초 동안 잠깁니다.
- 비밀번호는 원문으로 저장하지 않습니다. 소금(salt)을 친 scrypt 해시만 `data/accounts.json`에 저장되며, 이 폴더는 GitHub에 올리지 않습니다.
- 로그인 유지는 HttpOnly 쿠키로 합니다. 비밀값이 화면·주소창·페이지 저장소에 나타나지 않습니다.
- 실명이나 연락처 대신 별명을 쓰고, 다른 사이트의 비밀번호는 쓰지 마세요.

## 조작

| 키 | 동작 |
|---|---|
| `←` `↑` `↓` `→` | 내 개미 이동 |
| `E` | 노란 화살표가 뜬 물건 사용 / 열린 창 닫기 |
| `B` / `S` | 컴퓨터 책상 앞에서 선택한 종목 1주 매수 / 매도 |
| `Esc` | 열린 창 닫기 |
| (컴퓨터 안) `↑` `↓` | 종목 선택 |

시작·일시정지·다시 시작 버튼은 없습니다. 시장은 모두의 것이라 멈추지 않고 흘러갑니다.

방 위쪽에는 최신 사건 자막과 접속자 순위가 있고, 모든 개미 머리 위에 닉네임이 떠 있습니다.

## 규칙: 도전

| 항목 | 내용 |
|---|---|
| 시장 | 1.2초 = 1거래일. 접속자가 한 명이라도 있으면 계속 흐름. 모두가 같은 시세·같은 사건 |
| 시작 | 로그인하면 현금 100만 원으로 **1회차 도전** 시작 |
| 성공 | 총자산 115만 원(+15%) 이상 |
| 실패 | 총자산 85만 원(-15%) 이하, 또는 도전 60거래일 안에 목표 미달 |
| 다음 | 결과 창과 기록이 남고, 바로 다음 회차 도전이 100만 원으로 시작 |
| 난이도 | 없음. 모든 참가자가 같은 조건 |

## 주가 알고리즘 (AI 없이 자동)

매일 `market.js`의 `stepDay()`가 다음 순서로 시장을 한 번 움직입니다.

1. **날씨**: 계절(20거래일 ≈ 한 달)별 확률표에서 오늘 날씨를 뽑습니다. 어제 날씨가 50% 확률로 이어집니다. 폭염·한파·폭우·태풍·미세먼지가 시작되면 **날씨 사건**이 생겨, 그 날씨에 반응하는 종목(예: 폭염 → 음료·에어컨 상승, 농산물 하락)을 움직입니다.
2. **사건**: 하루 0~2건을 18가지 사건 틀에서 가중치대로 뽑습니다. 틀마다 대상 종목·결과(성공/실패 확률)·제목 문구·영향 범위가 정해져 있고, 매번 무작위 값으로 새 기사가 만들어집니다.
   - 회사: 신제품 출시(호평 60%/혹평), 실적 발표(어닝 서프라이즈/쇼크), **신약 임상**(성공 45%·허가 15%·실패 40%), 대규모 수주, 화재 사고, 리콜, 특허 소송, 자사주·배당, 인수 소문(오른 뒤 되돌아감), 경영 비리
   - 업종: 반도체 가격, 전기차·친환경 보조금, 감염병 유행
   - 시장 전체: 금리 인상/인하, 환율, 유가, 해외발 급락, 외국인 대량 매수
3. **사건 반영**: 영향받는 종목은 그날 바로 `j`만큼 움직이고, 여파 `d`가 다음 날부터 매일 70%씩 줄어들며 이어집니다.
4. **매일의 움직임**: 종목 수익률 = 베타 × 시장 공통 변동 + 업종 공통 변동 + 종목 고유 변동(**변동성 1.2%**) + 남은 여파 + 기준가로 돌아오려는 힘. 가격은 한국 시장 호가 단위로 맞춥니다.

종목마다 **태그**(수출·금리 민감·더위 수혜·추위 수혜·비 수혜·여행·태풍·유가 수혜/피해·미세먼지·전기차·친환경·감염병 등)가 있어서, 어떤 사건이 어떤 회사에 영향을 주는지 정해집니다. 30개 종목은 업종 6개에 5개씩입니다.

| 업종 | 종목 |
|---|---|
| IT·반도체 | 한빛전자, 별빛반도체, 누리소프트, 바다통신, 구름게임즈 |
| 바이오·제약 | 새싹제약, 푸른바이오, 하늘의료기, 들꽃헬스, 미르진단 |
| 식품·생활 | 푸른식품, 햇살음료, 고소제과, 맑은생활, 풍년농산 |
| 에너지·화학 | 별빛에너지, 해님태양광, 바람에너지, 단단화학, 따뜻가스 |
| 자동차·운송 | 질주자동차, 씽씽배터리, 하늘항공, 바닷길해운, 길벗물류 |
| 유통·레저 | 놀자여행, 포근패션, 시원가전, 모두마트, 별밤엔터 |

알고리즘 점검: `node market.js`를 실행하면 60거래일 × 300판을 모의로 돌립니다. 가격 오류·호가 단위·종목 수를 확인하고, 사건 수·지수와 종목 수익률 분포를 출력합니다.

## 효과와 선택권

효과는 **내 도전 성공, 내 도전 실패, 시장 급락 사건** 세 가지에서만 실행됩니다(화면 색 + 큰 개미 + 짧은 소리, 급락 때는 방이 흔들림).
상단의 **소리 끄기**는 재생 중인 소리를, **움직임 줄이기**는 흔들림·걸음 들썩임·깜빡임·창밖 비·눈의 움직임을 바로 멈춥니다.

## 확인 방법

| 검사 | ① 어디로 가나요 | ② 무엇을 하나요 (3단계 이내) | ③ 통과 모습 | ④ 안 될 때 모습 |
|---|---|---|---|---|
| 입장 | 시크릿 창 → localhost:5000 | 새 닉네임+비밀번호 → 입장 → 같은 닉네임, 다른 비밀번호로 다시 입장 | 처음엔 "계정을 새로 만들었어요", 두 번째는 "비밀번호가 맞지 않습니다" | 같은 닉네임이 두 개 생김, 틀린 비밀번호로 입장됨 |
| 여러 명 | 창 두 개로 서로 다른 닉네임 입장 | 한쪽 창에서 방향키로 이동 | 다른 창에도 그 개미와 이름표가 보이고 같이 움직임, 두 창의 시세가 같음 | 상대가 안 보이거나 시세가 다름 |
| 색 바꾸기 | 왼쪽 방 고양이 옆 | 색 발판 위로 이동 → E | 내 개미 몸 색이 바뀌고 다른 창에서도 같은 색 | 색이 안 바뀜 |
| 거래 (C06·C12) | 왼쪽 방 컴퓨터 책상 앞 | B를 1초 안에 10번 | 보유 정확히 +10주 (현금이 충분할 때) | +9 이하 또는 +11 이상 |
| HTS | 책상 앞 | E → 업종 탭 → 종목 눌러 수량 입력 후 매수 | 잔고·체결 내역에 반영 | 주문이 안 되거나 두 번 들어감 |
| 도전 결과 (C07) | 아무 곳 | 거래하지 않고 60거래일(약 72초) 기다리기 | "기간 만료(목표 미달)" 실패 창, 캐비닛 기록 +1, 다음 회차 시작 | 결과 창이 안 뜸 |
| 해상도 (C10·C11) | F12 → 기기 툴바 | 1366×768, 1920×1080 | 가로 스크롤 없음, 방·이름표·순위표가 보임 | 잘림, 가로 스크롤 |
| 포커스 (C13·C14) | 이동 중 | 방향키를 누른 채 다른 창 클릭 → 돌아오기 | 개미가 혼자 걷지 않고 계좌 그대로 | 혼자 걸어감, 값 초기화 |
| 10분 실행 (C16·C17) | F12 → Console | 10분 동안 플레이 | 계속 조작 가능, 빨간 오류 0건 | 멈춤 또는 빨간 오류 |
| 저장 (C24·C25) | F12 → Console | `localStorage.setItem('stockGame.v2','{깨짐')` → 새로고침 | 노란 안내 + 정상 시작 | 빈 화면, 콘솔 오류 |
| 효과 (C26·C27) | 플레이 중 | 소리 끄기/움직임 줄이기 켜기 | 바로 멈춤 | 계속 남 |

1. `VOL = 0.012`로 서버를 켜고 도전 10회 → 캐비닛 표의 '1.2%' 줄을 아래에 적기

3. 범위·중앙값·반복되는 실패 원인을 근거로 최종값 고르기

## 제출문: AI 활용 구분 (C31)

**① AI에게 맡긴 일**
- 코드 전체(`server.js`, `market.js`, `index.html`, `style.css`, `pixel.js`, `game.js`)
- 30개 종목·태그·사건 틀·날씨 확률표와 주가 알고리즘, 📘 배우기 문장, 용어 사전 초안

- 자동 검사와 이 문서, [제작과정.md](제작과정.md)

**② 학생이 직접 판단한 일**
- 주제를 '학습이 들어간 주식 시뮬레이션'으로 정함
