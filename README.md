# 🏘️ 나의 작은 사회 — 다 같이 사는 작은 마을 게임

주식을 사고팔고, 편의점에서 일하고, 은행에 돈을 맡기는 **작은 사회**입니다. 링크에 접속한 사람이 모두 **같은 마을·같은 주식시장·같은 시간** 속에서 함께 사는, 끝이 없는 게임입니다. (예전 이름: 개미 투자 교실 — 주식만이 아닌 작은 사회로 세계관을 넓히며 이름을 바꿨습니다.)
위에서 내려다본 픽셀 집 안을 방향키(또는 WASD)로 돌아다니며 컴퓨터(증권 HTS)로 30개 종목을 사고팝니다.
장은 닫히지 않아 언제든 사고팔 수 있고, 집 밖에서는 알바·동전 줍기·은행 예금으로도 돈을 벌 수 있습니다.
날씨와 신제품·신약·실적·금리·유가 같은 사건이 **AI 없이 자동으로** 일어나 주가를 움직이고,
TV 뉴스의 📘 배우기와 책장의 용어책으로 주가가 왜 움직이는지 익힙니다.

- 외부 라이브러리 없이 Node.js 내장 기능과 HTML·CSS·JavaScript만 씁니다. 그래픽은 모두 코드로 그립니다.
- **그래픽 두 가지**: 화면 위쪽 **그래픽** 메뉴에서 **고화질**(기본, 부드러운 도형·그라데이션·그림자)과 **픽셀**(도트 그래픽)을 바로 바꿀 수 있고, 고른 것은 이 브라우저에 저장됩니다. 지도·충돌·상호작용은 두 그래픽이 똑같습니다. 고화질에서는 컴퓨터·TV·책·칠판·캐비닛·은행 창도 둥근 모서리와 부드러운 그림자로 바뀝니다. 아이콘은 컬러 이모지, 차트는 4배 해상도 캔들, TV는 생성한 캐릭터가 앵커인 뉴스 스튜디오로 나옵니다.
- 고화질 그래픽을 넣기 전의 코드 전체는 Git 태그 `pixel-v1`로 백업해 두었습니다. (`git checkout pixel-v1`)
- 만든 과정은 [제작과정.md](제작과정.md)에 정리했습니다.

## 실행

```bash
node server.js
```

브라우저에서 http://localhost:5000 을 엽니다. 다른 창이나 다른 브라우저로 접속하면 여러 명이 함께 할 수 있습니다.

| 주소 | 화면 |
|---|---|
| `/` | **메인 홈페이지**: 지금 마을 바깥 풍경(실시간, 사람·동전·전광판까지 게임 그림 그대로), 방금 들어온 뉴스, 할 수 있는 일, 부자 순위·최근 뉴스, 처음 하는 법, **마을로 들어가기** 버튼 |
| `/play` | **게임** (닉네임·비밀번호 입장). 왼쪽 위 제목을 누르면 홈페이지로 |

홈페이지는 마을 모습만 보는 것이라 접속자로 세지 않습니다(`/api/poll?peek`). 아무도 게임 안에 없으면 시계·시세는 멈춘 채로 보입니다.

### 다른 사람과 같이 하기 (임시 인터넷 주소)

내 PC가 켜져 있는 동안, 다른 곳에 있는 사람도 같은 게임에 들어올 수 있습니다. 무료 Cloudflare 터널을 씁니다. 가입은 필요 없습니다.

1. 한 번만 설치: `winget install Cloudflare.cloudflared`
2. 프로젝트 폴더의 **`share.bat`** 을 더블클릭합니다. 게임 서버가 켜지고, 창에 `https://….trycloudflare.com` 주소가 나옵니다.
3. 그 주소를 친구에게 보내면 됩니다. 각자 닉네임과 비밀번호로 들어옵니다.

- `share.bat` 창을 닫거나 PC를 끄면 주소가 사라집니다. 다시 켜면 **새 주소**가 나옵니다. 계정과 자산은 `data/`에 남아 있어 그대로 이어집니다.
- 터널로 들어온 접속(https)에서는 로그인 쿠키에 `Secure`를 붙여 https로만 오가게 합니다.
- 무료 터널은 실시간 스트림을 붙잡아 두었다가 한꺼번에 보내는 일이 있습니다. 그래서 3초 안에 실시간 소식이 안 오면, 화면이 0.5초마다 최신 상태를 직접 받아 옵니다(`/api/poll`).
- 다른 사람의 위치는 받은 자리로 바로 옮기지 않고, 그 자리까지 **걷는 속도로 따라가게** 그립니다(뒤처지면 더 빨리). 그래서 0.5초마다 받아도 순간이동처럼 끊겨 보이지 않고, 걷는 동안 몸도 들썩입니다.

## 입장 (닉네임 + 비밀번호)

- 처음 쓰는 닉네임이면 계정이 **자동으로 만들어지고** 100만 원으로 시작합니다.
- 이미 있는 닉네임이면 **비밀번호가 같을 때만 로그인**됩니다. 5번 연속으로 틀리면 30초 동안 잠깁니다.
- 비밀번호는 원문으로 저장하지 않습니다. 소금(salt)을 친 scrypt 해시만 `data/accounts.json`에 저장되며, `data/` 폴더는 GitHub에 올리지 않습니다.
- 로그인은 HttpOnly 쿠키로 유지됩니다. 서버에는 쿠키 값의 해시만 저장되므로 서버를 다시 켜도 로그인이 이어집니다.
- 실명이나 연락처 대신 별명을 쓰고, 다른 사이트의 비밀번호는 쓰지 마세요.

## 조작

| 키 | 동작 |
|---|---|
| `←` `↑` `↓` `→` 또는 `W` `A` `S` `D` | 내 개미 이동 (TV·책에서는 `A`/`D`로도 넘김) |
| `E` | 노란 화살표가 뜬 물건 사용 / 동전 줍기 / 열린 창 닫기 |
| `B` / `N` | 컴퓨터 책상 앞에서 선택한 종목 1주 매수 / 매도 (언제든). 매도는 예전엔 `S`였지만 S가 이동 키가 되어 `N`으로 바꿈 |
| `Esc` | 열린 창 닫기 |
| (TV·책) `←` `→` | 이전·다음 뉴스 / 앞·다음 장 |
| (컴퓨터) `↑` `↓` | 종목 선택 |

### 휴대폰으로 하기

- 손가락으로 쓰는 기기(휴대폰·태블릿)에서는 화면 **왼쪽 아래에 조이스틱**, **오른쪽 아래에 E 버튼**이 나옵니다. 조이스틱은 방향키와 같고 많이 밀수록 빨리 걷습니다. E 버튼은 키보드 E와 똑같습니다(물건 사용·동전 줍기·창 닫기).
- **게임 화면을 터치하면 전체화면**이 되고, 지원하는 브라우저(안드로이드 크롬 등)에서는 **가로로 고정**됩니다. 아이폰 사파리는 전체화면·가로 고정을 막아 두어서, 휴대폰을 직접 가로로 돌려야 합니다.
- 가로 화면이 낮을 때(높이 500px 이하)는 머리줄을 숨기고, 상태판(시각·현금·예금·주식·총자산·오늘 수익률·새 뉴스)을 방 왼쪽 좁은 칸으로 옮겨 방이 화면 높이를 꽉 채웁니다. 그래픽 바꾸기·로그아웃은 세로 화면에서 할 수 있습니다.
- 컴퓨터(HTS)는 좁은 화면에서 한 줄로 쌓여 위아래로 넘겨 봅니다.

시작·일시정지·다시 시작·클리어·게임 오버는 없습니다. 계좌는 계정에 저장되어 계속 이어집니다.

## 게임 시계 (장은 24시간)

게임 시간은 **실제 1분 = 게임 30분**(실제 2초 = 게임 1분)으로 흐릅니다. 게임 하루는 실제 48분입니다. **장 개장·마감이 없어** 밤낮없이 언제든 주식을 사고팔 수 있습니다.

| 시간 | 일어나는 일 |
|---|---|
| 언제나 | **실제 1초마다** 시세가 조금씩 움직임, 주식 거래 가능 |
| 실제 5분마다 | 뉴스(사건) 하나 발생 (게임 하루에 약 9.6번) |
| 자정(오전 12:00) | **하루가 바뀜**. 오늘 시세가 일봉 하나로 확정되고 곧바로 새 일봉 시작, 은행 예금 이자 지급, 내 자산 기록, 새 날씨와 오늘 사건 시각이 정해짐, 알바 횟수 초기화 |

벽시계·화면 위 시각으로 지금 시각을 알 수 있습니다. 밤이 되면 바깥이 어두워지는 것은 그대로입니다. 게임 시계는 접속한 사람이 한 명이라도 있을 때만 흐릅니다.

### 오늘 수익률 계산 (게임 하루마다 0%부터)

**오늘 수익률 = 총자산 ÷ (오늘 자정의 총자산 + 그 뒤 알바·동전·예금 이자로 번 돈) − 1**

게임 자정마다 그때의 총자산이 새 기준이 되어 0%에서 다시 시작합니다(자정 이자는 기준에 먼저 들어감). 알바·동전·이자로 번 돈은 기준 금액에도 더해서, 주식으로 늘리거나 줄인 만큼만 나타납니다. 상태 줄·캐비닛·HTS 순위·접속자 순위·개미 표정이 모두 이 식을 씁니다. 전광판 TOP 10은 그대로 **총자산** 순서입니다.

## 집 밖

| 장소 | 하는 일 |
|---|---|
| 🏪 24시 편의점 (왼쪽 위) | **알바**: E → 8초 동안 일하고 시급 15,000원. 하루에 3번까지(자정에 초기화) |
| 🏦 개미은행 (오른쪽 위) | **예금·출금**: 맡긴 돈은 줄지 않고 매일 자정에 이자(기본 하루 0.10%)가 붙음. 금리 인상 뉴스면 이자율이 오르고, 인하 뉴스면 내림 |
| 🪙 잔디 위 동전 | 가끔 나타나는 동전 위에서 E → 100~500원. **주워 봐야 얼마인지 알 수 있음**(서버가 금액을 미리 보내지 않음). 먼저 줍는 사람이 임자 |
| 📟 전광판 (오른쪽 아래) | **자산 순위 TOP 10**: 접속하지 않은 사람까지 모든 계정의 총자산 순위. 내 이름은 초록색 |
| 🚪 집 문 (위쪽 가운데) | 위로 걸어가면 집 안으로 |

밤이 되면 바깥이 어두워집니다. 같은 장소(집 안/집 밖)에 있는 사람끼리만 서로의 개미가 보입니다.

## 화면

- 위쪽 상태 줄: 시각·장 상태, 날씨(계절), 개미지수, 현금, 은행 예금, 주식 평가액, 총자산, 오늘 수익률(주식으로 번 만큼만, 자정마다 0%부터), 새 뉴스, 배운 개념
- 상태 줄의 "새 뉴스": 아직 TV로 안 본 뉴스 개수 (방 그림을 가리지 않도록 자막 대신 숫자로만 표시)
- 방 오른쪽 위: "👥 n명 접속 · 나 k위" 칩 (누르거나 마우스를 올리면 순위 펼침)
- 방 위쪽 가운데: 4초 뒤 사라지는 알림 · 방 그림 바로 아래: 조작 안내 줄 (그림을 가리지 않음)
- 방 크기: 픽셀 그래픽은 화면에 맞는 가장 큰 정수 배율(1366×768에서 3배)로 그려 도트가 고릅니다. 고화질 그래픽은 화면에 들어가는 최대 크기까지 키우고, 캔버스 해상도도 그 크기에 맞춰 흐려지지 않게 합니다.
- 새로고침(F5)하거나 다시 접속해도 **마지막으로 서 있던 자리와 장소(집 안/밖)** 에서 시작합니다. 위치는 계정에 저장됩니다.
- 캐릭터는 정장 차림의 **사람**입니다. 고화질 그래픽은 이미지 생성 도구로 만든 캐릭터 그림(`assets/person-색.png`, 재킷 색만 다른 5장)을 쓰고, 기분은 머리 위 아이콘(♪ 기쁨 · 💧 울상 · ❗ 깜짝)으로 보여 줍니다. 픽셀 그래픽은 16×16 도트 사람이 표정과 걸음을 직접 바꿉니다.
- 모든 캐릭터 머리 위에 닉네임이 뜹니다. 여러 명이 겹치면 **가장 앞(아래쪽)에 서 있는 사람의 이름만** 보입니다.

## 주가 알고리즘 (AI 없이 자동)

`market.js`가 시장을 움직입니다. 하루(자정~자정, 실제 48분) = 일봉 하나 = 실제 1초 × 2880번입니다.

1. **새 하루 (`openDay`, 자정)**: 계절(20거래일 ≈ 한 달)별 확률표에서 오늘 날씨를 뽑습니다(어제 날씨가 50% 확률로 이어짐). 폭염·한파·폭우·태풍·미세먼지가 시작되면 **날씨 사건**이 자정 뉴스로 나옵니다.
   - **🚀 대박 호재**(가끔, 게임 약 12일에 1번): 세계를 바꿀 신제품 품절 대란·완치 신약 승인·세계 최초 신기술. 그 종목이 한 번에 **20~40%** 뛰고, 그 뒤 며칠 동안 하루 2~4%씩 더 오르려는 힘이 남습니다(매일 30%씩 약해짐).
   - **뉴스는 실제 5분마다 하나**(1초 시세 300번마다, 게임 하루 약 9.6번) 19가지 사건 틀에서 뽑아 올라옵니다. 접속자가 없으면 시세처럼 멈춥니다.
   - 일반 뉴스 하나의 세기는 순간 상승·하락 ×0.55, 며칠 남는 여파 ×0.3으로 줄였습니다. 뉴스가 하루 3번이던 때보다 3배 넘게 자주 나와도 하루 전체 흔들림과 시장 전체 방향이 비슷하게 유지됩니다. 🚀 대박 호재는 세기를 줄이지 않고, 뽑힐 비중만 낮춰 드물게 했습니다.
   - TV·컴퓨터 뉴스에는 올라온 때가 "오늘 오후 4:00", "어제 오전 8:00", "3일 전 오전 12:00"처럼 나옵니다.
2. **실제 1초마다 (`stepTick`)**: 5분(300번)이 찼으면 뉴스를 냅니다. 그리고 하루치 움직임의 1/2880만큼 움직입니다. 한 번의 크기를 √2880로 나누므로 하루 변동성은 횟수와 상관없이 같습니다.
   - 종목 수익률 = 베타 × 시장 공통 변동 + 업종 공통 변동 + 종목 고유 변동(**변동성 하루 1.2%**) + 사건 여파 (+ 처음 가격의 30% 아래일 때만 받쳐 주는 힘)
   - **평균·기준가로 끌어당기는 힘은 없습니다.** 한 기업이 계속 잘되면 끝없이 오를 수 있습니다. 대신 **상장폐지는 없습니다**. 처음 가격의 30% 아래로 떨어지면 위로 받쳐 주는 힘이 생기고, 10% 아래로는 절대 내려가지 않습니다.
   - **화면의 "왜 움직였나"는 이 식을 그대로 나눠 보여 줍니다.** 📰 오늘 뉴스가 바로 올리거나 내린 몫(사건별 시각과 %) · 🌊 나머지(시장·업종·종목의 무작위 흐름) · ⏳ 지난 뉴스의 남은 여파(하루 몇 %씩, 매일 30%씩 약해짐) · 🛟 상장폐지를 막는 받침 힘(처음 가격의 30% 아래일 때만). 여파와 받침 힘은 하루 0.1% 이상일 때만 보입니다(`market.forcesOf`).
3. **하루 마감 (`closeDay`, 자정)**: 사건의 여파가 하루만큼(30%) 줄어듭니다. 오늘 가격이 일봉으로 확정됩니다(최근 60거래일 보관).

사건은 틀마다 대상 종목, 결과 확률(예: 신약 임상 성공 45%·허가 15%·실패 40%), 제목 문구, 영향 범위가 정해져 있고, 매번 무작위 값으로 새 기사가 만들어집니다.

- 회사: 신제품 출시(호평 60%/혹평), 실적 발표(어닝 서프라이즈/쇼크), 신약 임상, 대규모 수주, 화재 사고, 리콜, 특허 소송, 자사주·배당, 인수 소문(오른 뒤 되돌아감), 경영 비리
- 업종: 반도체 가격, 전기차·친환경 보조금, 감염병 유행
- 시장 전체: 금리 인상/인하(은행 이자율도 함께 변동), 환율, 유가, 해외발 급락, 외국인 대량 매수

종목마다 **태그**(수출, 금리 민감, 더위 수혜, 추위 수혜, 비 수혜, 여행, 태풍, 유가 수혜/피해, 미세먼지, 전기차, 친환경, 감염병)가 있어서, 어떤 사건이 어떤 회사에 영향을 주는지 정해집니다.

|---|---|
| IT·반도체 | 한빛전자, 별빛반도체, 누리소프트, 바다통신, 구름게임즈 |
| 바이오·제약 | 새싹제약, 푸른바이오, 하늘의료기, 들꽃헬스, 미르진단 |

| 에너지·화학 | 별빛에너지, 해님태양광, 바람에너지, 단단화학, 따뜻가스 |

알고리즘 점검: `node market.js`를 실행하면 60거래일 × 100판을 모의로 돌립니다(약 1분 30초). 가격 오류, 호가 단위, 종목 수, 오늘 일봉 = 현재가, 예금 이자율 범위를 확인하고, 사건 수·지수와 종목 수익률 분포를 출력합니다.
