# 🐜 개미 투자 교실 — 픽셀 주식 시뮬레이션 학습 게임

정장 입은 개미가 되어 **위에서 내려다본 픽셀 사무실**을 방향키로 돌아다니며 주식을 사고파는 게임입니다.
컴퓨터 책상에서 거래하고, TV에서 뉴스를 보며 📘 배우기를 읽고, 책장에서 용어를 찾아보며
**뉴스가 주가를 움직이는 원리**와 **분산투자·경기방어주·금리·배당** 같은 기초 개념을 익힙니다.

- 로그인·회원가입 없이 바로 플레이할 수 있습니다.
- 외부 이미지·라이브러리 없이 HTML·CSS·JavaScript만 사용합니다. 그래픽은 모두 코드로 픽셀을 찍어 그립니다.
- 만든 과정은 [제작과정.md](제작과정.md)에 정리했습니다.

## 실행

```bash
python -m http.server 5000 --bind 127.0.0.1
```

브라우저에서 http://localhost:5000 을 엽니다.

## 조작

| 키 | 동작 |
|---|---|
| `←` `↑` `↓` `→` | 개미 이동 (누르고 있는 동안) |
| `Space` (또는 `E`) | 노란 화살표가 뜬 물건 사용 |
| `B` / `S` | 1주 매수 / 1주 매도 — **컴퓨터 책상 앞에서만** |
| `1` `2` `3` | 거래할 종목 선택 (화면 맨 아래 종목 칩 클릭도 가능) |
| `P` | 일시정지 / 계속 |
| `R` | 다시 시작 |
| `Enter` | 게임 시작 |
| `Esc` | 열린 창 닫기 |

화면 아래 버튼(시작·매수·매도·일시정지·다시 시작)으로도 같은 조작을 할 수 있습니다.
게임 화면은 방 하나로 꽉 채웠습니다. 방 위쪽 빨간 자막에는 최신 뉴스가 나오고, 방 아래 안내 줄에는 조작 요약이나 가까운 물건이 표시됩니다. 맨 아래 종목 칩에는 가격·등락률·보유 주식이 나옵니다.

## 사무실 안내

| 방 | 물건 | Space를 누르면 |
|---|---|---|
| 왼쪽 (벽돌 방) | 💻 컴퓨터 책상 | 앞에 서 있으면 B/S로 1주씩 바로 거래. Space를 누르면 컴퓨터가 켜지고 **개미증권 HTS** 실행 |
| | 📚 책장 | 주식 용어 사전 |
| | 📅 달력 · 🪟 창문 | 달력 = 오늘 거래일, 창밖 해의 위치 = 진행 정도, 하늘 색 = 게임 상태 |
| 가운데 (거실) | 📺 TV | 새 뉴스가 오면 **!** 말풍선. 뉴스와 📘 배우기를 읽으면 '배운 개념' 증가 |
| | 🧑‍🏫 칠판 | 게임 규칙 |
| 오른쪽 (침실) | 🗂 캐비닛 | 플레이 기록, 난이도별 통계 |
| | 🛏 침대 | 쉬기(일시정지) / 일어나기 |

책장·칠판·TV·캐비닛 창을 보는 동안에는 시간이 멈추고, 창을 닫으면 이어서 진행됩니다.

## 💻 컴퓨터 (개미증권 HTS)

책상 앞에서 Space를 누르면 실제 증권사 프로그램처럼 생긴 화면이 열립니다. 주식 기능만 들어 있습니다.

| 영역 | 내용 |
|---|---|
| 관심 종목 | 세 종목의 현재가·등락률. 클릭하거나 ↑↓로 선택 |
| 내 계좌 | 총자산, 수익률, 예수금(현금), 주식 평가액, 목표까지 남은 금액 |
| 현재가 | 종목명·업종, 현재가, 전일 대비(▲▼)·등락률, 기간 고가·저가, 보유·평단 |
| 일봉 차트 | 하루 한 칸 픽셀 캔들 (빨강 상승·파랑 하락·주황 점선 = 내 평단) |
| 잔고 / 체결 내역 / 기업 정보 탭 | 보유 종목별 평가손익·수익률 / 이번 판 매수·매도 기록 / 회사 설명·시장 민감도(베타)·관련 뉴스 |
| 호가 | 매도 대기 5칸(파랑)과 매수 대기 5칸(빨강), 한국 시장의 호가 단위와 잔량 막대 |
| 주문 | 수량 입력(1주·10주·최대 매수·전량 버튼), 주문 금액·매수 가능 수량·보유 수량, 매수·매도 |

- 실제 장처럼 **컴퓨터를 보는 동안에도 주가가 계속 움직입니다**. 생각할 시간이 필요하면 P로 일시정지하세요.
- 주문 한 번은 체결 한 번입니다. 현금이나 보유 수량이 부족하면 체결되지 않고, 가능한 최대 수량을 알려 줍니다.
- Esc 또는 [로그아웃]으로 닫습니다.

## 규칙

| 항목 | 내용 |
|---|---|
| 시작 | 현금 100만 원, 종목 3개(한빛전자·푸른식품·별빛에너지, 모두 가상 회사) |
| 진행 | 1.2초 = 1거래일, 최대 60거래일. 뉴스가 오면 주가가 바로 움직이고, 그 여파가 며칠 이어짐 |
| 성공 | 총자산 115만 원(+15%) 이상 |
| 실패 | 총자산 85만 원(-15%) 이하, 또는 60일 안에 목표 미달 |
| 학습 | 뉴스 8종마다 📘 배우기, 용어 사전 9개, 판이 끝나면 내 플레이에 맞춘 교훈 |

개미의 표정도 상황을 알려 줍니다: 수익이면 웃음, 손실이면 울상, 일시정지면 졸음, 시장 급락이면 깜짝.

## 저장 정책

| 구분 | 값 |
|---|---|
| 새 판마다 초기화 | 거래일, 현금, 보유 주식·평단, 주가·차트, 뉴스, 개미 위치, 상태 |
| 보존 (localStorage `stockGame.v1`) | 플레이 기록(최대 200판), 최고 수익률, 배운 개념, 설정(난이도·소리 끄기·움직임 줄이기) |
| 빈 값 / 손상 값 | 형식을 검사해 통과한 값만 쓰고, 실패하면 기본값으로 시작하며 상단에 안내 표시 |

## 효과와 선택권

효과는 **성공, 실패, 시장 급락 뉴스** 세 사건에서만 실행됩니다(화면 색 + 큰 개미 + 짧은 소리, 급락 때는 방이 흔들림).
상단의 **소리 끄기**를 켜면 재생 중인 소리가 바로 멈춥니다.
**움직임 줄이기**를 켜면 흔들림, 걸을 때 들썩임, 깜빡임이 바로 멈춥니다. 처음 접속하면 운영체제의 '동작 줄이기' 설정을 따릅니다.
개인정보와 비밀값(API 키 등)은 쓰지 않습니다.

## 확인 방법

| 검사 | ① 어디로 가나요 | ② 무엇을 하나요 (3단계 이내) | ③ 통과 모습 | ④ 안 될 때 모습 |
|---|---|---|---|---|
| 한 판 (C03~C07) | 시크릿 창 → localhost:5000 | Enter → 방향키로 왼쪽 방 책상 앞 → B로 몇 주 매수 후 기다리기 | 매수마다 보유 +1주, 결국 성공/실패 창 | 이동 안 됨, 거래일 멈춤, 결과 창 없음 |
| 재시작 (C08·C09) | 결과 창 | [다시 시작] 또는 R | 거래일 0, 현금 100만, 보유 0주, 개미가 처음 자리로 | 이전 판 값이 남음 |
| 해상도 (C10·C11) | F12 → 기기 툴바 | 1366×768, 1920×1080 설정 → 좌우 스크롤 확인 | 가로 스크롤 없음, 모든 버튼 보임 | 버튼 잘림, 가로 스크롤 |
| 연속 입력 (C12) | 책상 앞에서 진행 중 | B를 1초 안에 10번 | 보유 정확히 +10주 (현금이 충분할 때) | +9 이하 또는 +11 이상 |
| 창 크기·포커스 (C13·C14) | 진행 중 | 방향키를 누른 채 다른 창 클릭 → 돌아오기 → P | 자동 일시정지, 개미가 혼자 걷지 않음, P로 이어짐 | 값 초기화, 혼자 걸어감, 여러 날이 한꺼번에 지남 |
| 일시정지 (C15) | 진행 중 | P (또는 침대에서 Space) → 5초 대기 → P | 정지 중 거래일·주가·위치 그대로 | 정지 중 거래일 증가 |
| 10분 실행 (C16·C17) | F12 → Console | 10분 동안 여러 판 → 콘솔 확인 | 계속 조작 가능, 빨간 오류 0건 | 멈춤 또는 빨간 오류 |
| 저장 (C22~C25) | F12 → Console | `localStorage.setItem('stockGame.v1','{깨짐')` → 새로고침 (빈 값은 `''`) | 노란 안내 + 기본값으로 정상 시작 | 빈 화면 또는 콘솔 오류 |
| 효과 (C26·C27) | 진행 중 | 판을 끝내거나 급락 뉴스 대기 → 소리 끄기/움직임 줄이기 켜기 | 세 사건에서만 효과, 켜면 바로 멈춤 | 매수 때도 효과, 끈 뒤에도 계속 |

## 난이도 비교 (카드 3)

난이도는 **하루 변동성 값 하나**만 바꿉니다(낮음 1.2% · 보통 2.0% · 높음 3.2%). 나머지 규칙은 고정입니다.
판이 끝날 때마다 기록이 자동 저장되고, **🗂 캐비닛**에서 난이도별 판 수·성공 수·수익률 범위·중앙값·가장 잦은 실패 원인을 볼 수 있습니다.

1. 보통으로 10판 플레이 → 캐비닛의 '보통' 줄을 아래 표에 옮겨 적기
2. 난이도 하나만 바꿔 10판 플레이 → 같은 방식으로 적기
3. 범위·중앙값·반복되는 실패 원인을 근거로 최종값 고르기

## 제출문: AI 활용 구분 (C31)

**① AI에게 맡긴 일**
- 게임 규칙 초안(성공 +15% / 실패 -15% / 60거래일), 화면 구성, 코드 전체(`index.html`, `style.css`, `pixel.js`, `game.js`)
- 픽셀 스프라이트와 사무실 지도·가구 그래픽, 방향키 이동·충돌·상호작용
- 뉴스 사건과 📘 배우기 문장, 용어 사전 초안
- 해상도·연속 입력·일시정지·저장 손상 자동 검사, 이 문서와 [제작과정.md](제작과정.md)

**② 학생이 직접 판단한 일**
- 주제를 '학습이 들어간 주식 시뮬레이션'으로 정함
- 텍스트만 있는 화면 대신 2D 픽셀 그래픽으로 바꾸도록 요청
- 참고 이미지(아늑한 픽셀 사무실)를 골라, 보기만 하는 화면이 아니라 방향키로 직접 움직이는 게임으로 방향을 정함
